O projeto EcoSpot apresenta o desenvolvimento de uma plataforma digital orientada a incentivar e organizar a reciclagem em centros urbanos como a região de Sorocaba/SP.
Unindo geolocalização, modelagem relacional de banco de dados e um ecossistema de gamificação com acúmulo de pontos, o sistema busca solucionar a desinformação quanto
aos locais corretos de descarte e engajar a população. O trabalho aborda o escopo técnico completo do projeto, incluindo levantamento de requisitos, arquitetura em nuvem
(LGPD), prototipação de interface e análise financeira com um orçamento estimado em R$ 30.000,00. Adicionalmente, apresenta-se um plano detalhado para expansão futura
focado no cadastramento sistemático de PEVs (Pontos de Entrega Voluntária) e formalização de parcerias com o setor comercial e público.
